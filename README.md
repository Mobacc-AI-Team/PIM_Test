# Mobacc PIM Demo

Statische Vercel-ready demo voor een PIM-uitbreiding bovenop Exact Globe.

## Inhoud

- `index.html`: dashboard en schermstructuur
- `styles.css`: Mobacc-gebaseerde huisstijl
- `app.js`: eenvoudige view-switching en zoekgedrag

## Schermen

- Dashboard
- Centrale stamkaart
- Documenten & versies
- Datacompleetheid

## Lokaal openen

Open `index.html` direct in een browser of serve de map statisch, bijvoorbeeld:

```bash
python3 -m http.server 4173
```

## Vercel

Deze map kan direct als statische site naar Vercel worden gedeployed.
